# WP2_Perpus_TonyAfriza

A simple library book lending application built with **CodeIgniter 4** and **Bootstrap SB Admin**.

## Features
- Manage books
- Lend & return books
- Basic admin dashboard (SB Admin template)

## Requirements
- PHP 7.4+
- Composer
- MySQL / MariaDB
- CodeIgniter 4

## Installation
1. Clone this repository  
    ```bash
    git clone https://github.com/rizaton/WP2_Perpus_TonyAfriza.git
    ```
2. Install Dependencies
    ```bash
    composer install
    ```
3. Copy `.env.example` to `.env` and adjust your database settings.
4. Run database migrations
    ```bash
    php spark migrate
    ```
6. Start the development server
    ```bash
    php spark serve
    ```

## Usage
Open http://localhost:8080
in your browser.
